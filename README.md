# 李永乐式结构化讲解

一个借鉴李永乐老师公开课讲解结构的 AI 技能：从具体问题出发，通过直觉、定义和分步推导建立理解，再用迁移问题检验掌握程度。

本项目不是李永乐老师的官方作品，也不代表获得本人认可。借鉴的是教学组织方式，不冒充本人，不复刻身份、口头禅或个人经历。

## 使用

将本仓库作为名为 `liyongle-explanation` 的技能目录，交给支持 `SKILL.md` 的工具加载。明确指定使用该技能，例如：

> 使用 $liyongle-explanation，讲清楚为什么十二平均律中相邻半音的频率比是 2 的十二次方根。

> 像李永乐老师那样拆解贝叶斯定理，先用具体例子建立直觉，再推导公式。

技能只在用户明确要求这种讲法时启用。

## 讲解主线

1. 提出一个具体、可回答的问题。
2. 用贴切的类比、例子或最小模型建立直觉，并说明边界。
3. 引入必要定义和公式，逐步交代推导依据。
4. 回答开场问题，连接已有知识。
5. 用改变条件的迁移问题检验理解，必要时退回未掌握的步骤。

## 文件

- `SKILL.md`：技能规则与准确性要求。
- `agents/openai.yaml`：展示信息与显式调用配置。
- `cards/`：25 张公开课结构卡及 1 张访谈校准卡。
- `heldout.md`：来源说明、留出评估、失败记录与适用边界。

结构卡保留来源链接和重新组织的分析，不包含原视频、音频或完整转写。评估方法和局限以 `heldout.md` 为准；评估结果不保证所有题目都能正确讲解。
